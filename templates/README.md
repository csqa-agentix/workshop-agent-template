# 🟡 templates/ — blank files to copy from

| File | Copy it to | For |
|---|---|---|
| `agent.blank.md` | `my_agent/prompts/agent.md` | the agent's job description (mission, phases, rules, hand-over, answer format) |
| `skill.blank.md` | `my_agent/prompts/skills/<name>.md` | a reusable know-how file |

(For a blank tool, copy `my_agent/tools/_example_tool.py`. For planning, use `my_agent/BLUEPRINT.md`.)
